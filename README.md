
# Secure & Optimized REST API

A backend REST API built with Node.js, Express.js, SQLite, and JWT authentication.

## Features

- User Signup and Login
- Password Hashing with bcryptjs
- JWT Authentication
- Role-Based Authorization (Admin/User)
- Product CRUD Operations
- Input Validation
- Pagination
- Response Caching
- API Testing with Postman

## Tech Stack

- Node.js
- Express.js
- SQLite
- better-sqlite3
- JSON Web Token (JWT)
- bcryptjs
- Postman

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Go to the Backend Folder

```bash
cd backend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend folder and add the required variables used by the project.

Never share your real secrets or commit your `.env` file.

### 5. Start the Server

```bash
node server.js
```

The server runs on port 3000 by default.

## API Testing

Use Postman to test authentication and product endpoints.
